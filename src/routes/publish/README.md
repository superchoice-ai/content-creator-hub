# Publish route

This directory contains the Content Publishing Form route and supporting types/skeletons.

Primary editor: Lovable — start UI work in Lovable on branches named feat/lovable/* and map edits to these files. See CONTRIBUTING.md.

See docs/CONTENT_PUBLISHING_SPEC.md for the contract and UI mapping.

Files here:
- index.tsx — route component skeleton
- schema.ts — TypeScript interfaces for form state and AI contract

Do not implement production logic here; keep this skeleton in sync with Lovable UI components.
